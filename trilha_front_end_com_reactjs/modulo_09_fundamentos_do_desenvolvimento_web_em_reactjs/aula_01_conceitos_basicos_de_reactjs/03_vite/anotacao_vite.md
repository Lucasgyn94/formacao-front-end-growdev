# Vite

Vite é uma ferramenta que facilita o desenvolvimento de aplicações web. Ele fornece um servidor de desenvolvimento e prepara os arquivos da aplicação para publicação.

## Vite e React

- **React:** cria a interface usando componentes.
- **TypeScript:** verifica os tipos do código.
- **Vite:** executa o ambiente de desenvolvimento e gera o build.
- **npm:** instala dependências e executa scripts.

## Principais recursos

- Inicialização rápida do servidor de desenvolvimento.
- Atualização da interface ao salvar alterações no código.
- Suporte a projetos com React e TypeScript.
- Geração de arquivos otimizados para publicação.

## Criando um projeto com React e TypeScript

    npm create vite@latest meu-projeto -- --template react-ts
    cd meu-projeto
    npm install
    npm run dev

Após executar os comandos, abra o endereço exibido no terminal.

## Comandos principais

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: gera a versão da aplicação para publicação.
- `npm run preview`: permite visualizar o build localmente, sem publicar o site.
