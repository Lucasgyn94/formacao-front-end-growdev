# Deploy
* Processo de "mudar" um site ou aplicação para um servidor onde ele estará acessível pela internet.
* No caso de páginas estáticas, o deploy consistem em enviar todos os arquivos que compõem o nosso site (HTML, CSS, JavaScript e imagens) para um servidor.
* Em resumo, deploy é o ato de tornar um aplicativo ou site disponível para o público em um servidor.

## Como funciona o Deploy de páginas estáticas?
* O primeiro passo é escolher um provedor de hospedagem.
* Existem diversas opções de provedores de hospedagem para
sites estáticos. Listamos abaixo algumas opções gratuitas para
que você possa utilizar. Trataremos, na sequência deste material,
mais detalhadamente sobre o passo-a-passo para realizar o
deploy de um site simples em ambas as plataformas.

__GitHub Pages__: Totalmente gratuito para projetos públicos e só
permite o deploy de sites estáticos. Para saber mais sobre
esse provedor, acesse a documentação disponibilizada em
__GitHub Pages - GitHub Docs__

__Vercel__: Focada em performance e experiência do
desenvolvedor. O vercel permite o deploy de sites estáticos
como também de aplicações dinâmicas. Para saber mais
sobre esse provedor, acesse a documentação disponibilizada
em __Vercel Documentation__
