# Introdução à estilização e CSS
## CSS - Cascading Style Sheets
* Define a __apresentação (aparência) de documentos__ (como XML, HTML, XHTML, etc.)

* Determina __regras__ para um arquivo HTML.

## Tipos de CSS
* Existem três tipos: Inline, Interno, Externo

### Inline
* Inserido junto ao código HTML através do __atributo style__.

__Vantagens:__
  - Alta Prioridade
  - Espeficidade Garantida

### Interno
* Conhecido como CSS embutido

* Utilizamo a tag __<style>__ no cabeçalho (head) do documento HTML:

__Vantagens:__
  - Organização Local
  - Desenvolvimento Rápido
  - Controle Específico

### Externo
* Criado um arquivo externo ao documento html

* Esse arquivo deve ter a extensão .CSS

* __Para utilizar, é necessário importá-lo em uma tag link__

__Vantagens__
  - Separação de Conteúdo
  - Facilidade de Manutenção
  - Reutilização e Consistência
  - Desempenho e Flexibilidade
