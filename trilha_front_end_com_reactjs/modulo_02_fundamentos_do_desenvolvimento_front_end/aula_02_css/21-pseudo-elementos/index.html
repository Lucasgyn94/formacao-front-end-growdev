Este exemplo demonstra como a primeira letra pode ser destacada usando ::first-letter, criando um efeito de capitular como em livros antigos.

::first-line

Aqui a primeira linha do parágrafo está estilizada com o pseudo-elemento ::first-line. O texto ganha mais destaque, ideal para introduções de artigos ou posts.
