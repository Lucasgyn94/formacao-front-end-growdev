# Tabelas
* As tabelas HTML permitem que as pessoas desenvolvedoras da Web organizem os dados em linhas e colunas.
  * Títulos: <th>
  * Linhas: <tr>
  * Colunas: <td>

## Tabelas - Border
* Para adicionar uma borda, use a propriedade CSS __border__ nos elementos table, th e td.

## Tabelas - Size
* Use o atributo style com as propriedades de __width__ e __height__ para especificar o tamanho de uma tabela, linha ou coluna.

## Tabelas - Colspan e Rowspan
* Célula se estender por __várias colunas__, use o atributo colspan.
* Célula se estender por __várias linhas__, use o atributo rowspan
