Listas

Listas são tags utilizadas para agrupar texto, elementos com valores correlatos entre si

Tipos de listas

No HTML temos três tipos de listas:

  1. ordenadas (ol, numeradas)
  2. não ordenadas (ul, com marcadores)
  3. descrição/definição (dl, pares de termo/descrição)

Elas estruturam conteúdos, sendo itens de lista li essenciais para ol e ul, enquanto dt e dd são usados para definir termos.
