## Onde transformar sua imagem em um Favicon (Geradores)
Depois de baixar o seu ícone (ou se você quiser criar um do zero), use um destessites para gerar o código HTML e os arquivos corretos:

* __Favicon.io__: É o mais rápido e prático. Ele permite gerar um favicon a partir de uma imagem que você baixou, a partir de um Emoji, ou até mesmo digitando as iniciais do seu projeto (ele cria um ícone com texto e cor de fundo na hora).

* __RealFaviconGenerator.net__: Esse é o padrão ouro da indústria. Você faz o upload da sua imagem e ele gera todos os tamanhos necessários para PC, celular Android, iPhone e Mac. Além disso, ele te entrega o código HTML exato para você copiar e colar.
