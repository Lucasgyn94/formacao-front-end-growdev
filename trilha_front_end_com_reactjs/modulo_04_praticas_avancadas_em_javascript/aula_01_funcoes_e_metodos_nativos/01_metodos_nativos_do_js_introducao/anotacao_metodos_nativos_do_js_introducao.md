## MÉTODOS NATIVOS
* Os métodos nativos são recursos integrados a uma linguagem de programação para facilitar operações comuns.

* Assim, o programador não precisa criar esses processos do zero.

* O Javascript possui uma série de métodos nativos para auxiliar diversos processos, como:
  - Manipulação de strings;
  - Manipulação com números;
  - Controle de listas.
