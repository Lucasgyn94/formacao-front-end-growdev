# ERROS NO JAVASCRIPT
* Estamos sujeitos a enfrentar vários tipos de erro na programação em JavaScript, dentro os quais veremos alguns abaixo.

## SyntaxError
* Erro de sintaxe
* Acontece quando o JavaScript não consgue entender o código escrito.
* Impede todo o código de ser executado.

## ReferenceError
* Erro de referência inválida.
* Acontece quando o código tenta acessar um método ou variáel que não existe ou não está no escopo do script.
* Impede o código seguinte de ser executado.

## TypeError
* Erro de tipagem
* Acontece quando o código tenta executar uma operação em um tipo de dado incorreto.
* O valor que está sendo manipulado não é compatível com a operação.
* Impede o código seguinte de ser executado.
