**Tipos de API**

As APIs são interfaces que conectam duas aplicações diferentes. De acordo com o tipo de conexão, existem os seguintes tipos de API.

* API pública
* API privada
* API de parceiros

**API pública**

Uma API pública permite que **qualquer desenvolvedor ou empresa consiga acessá-la.** Esse tipo de API é geralmente disponibilizado por empresas que desejam expandir o uso de seus serviços ou dados para uma comunidade maior.

**Características:**

* Livre para desenvolvedores e empresas;
* Documentação aberta;
* Limitação de uso.

**API privada**

As APIs privadas são usadas internamente em empresas, de modo que **o acesso é restrito.** Ou seja, o público em geral não pode acessar os recursos.

**Características:**

* Apenas equipes internas podem usar;
* Possui forte camada de segurança para impedir acessos indevidos.

**API de parceiros**

APIs de parceiros estão expostas, mas apenas organizações e usuários previamente autorizados possuem acesso. São usadas geralmente para comunicação e integração entre duas empresas diferentes.

**Características:**

* Acesso controlado por meio de autenticação.
* Promove integração entre empresas.
