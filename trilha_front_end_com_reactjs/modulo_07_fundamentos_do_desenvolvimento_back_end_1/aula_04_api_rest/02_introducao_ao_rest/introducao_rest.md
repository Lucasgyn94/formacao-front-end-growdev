**O que é?**

Uma API REST é uma API que segue os princípios e restrições do **REST** (**Representational State Transfer**): um conjunto de regras e padrões para a construção de serviços de comunicação entre diferentes sistemas.

O padrão REST é amplamente utilizado para APIs web, pois fornece uma maneira simples e eficiente para a troca de dados entre aplicações e servidores.

**API ou API Rest?**

### API
* Qualquer tipo de interface de comunicação entre dois sistemas.

* Pode usar vários protocolos de comunicação (HTTP, TCP, etc.)

* Pode usar vários tipos de dados (pode ser binário, JSON, XML).

* Pode ser stateful ou stateless.

### API REST
* API que segue o padrão REST (Representational State Transfer).

* Usa o protocolo HTTP.

* Usa principalmente o formato JSON.

* Stateless (sem estado).


**HTTP**

O protocolo **HTTP** (**Hypertext Transfer Protocol**) é o método principal de comunicação na internet.

Ele segue um modelo de **requisição e resposta**, onde o cliente faz uma solicitação, e o servidor responde com os dados pedidos.
