# Verbos HTTP

### GET
* **Aplicação:** Listar/obter dados de um recurso.
* **Exemplo:**
  * `GET http://api.com/usuarios`
  * `GET http://api.com/usuarios/1`

---

### POST
* **Aplicação:** Criar um novo recurso.
* **Exemplo:**
  * `POST http://api.com/usuarios`

---

### PUT
* **Aplicação:** Atualizar todos os dados de um recurso.
* **Exemplo:**
  * `PUT http://api.com/usuarios/1`

---

### PATCH
* **Aplicação:** Atualizar parte de um recurso.
* **Exemplo:**
  * `PATCH http://api.com/usuarios/1`

---

### DELETE
* **Aplicação:** Excluir um recurso.
* **Exemplo:**
  * `DELETE http://api.com/usuarios/1`
