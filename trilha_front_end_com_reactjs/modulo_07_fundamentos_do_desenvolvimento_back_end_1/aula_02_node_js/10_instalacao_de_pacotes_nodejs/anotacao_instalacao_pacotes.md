# Instalação de Pacotes
* Podemos instalar um pacote com o comando:
```
npm install nome_pacote
```
ou
```
npm i nome_pacote
```
## Instalação como Desenvolvedor
* Caso o pacote não seja necessário para a produção, somente no desenvolvimento, podemos instalá-lo com o comando:
```
npm install nome_pacote -D
```
