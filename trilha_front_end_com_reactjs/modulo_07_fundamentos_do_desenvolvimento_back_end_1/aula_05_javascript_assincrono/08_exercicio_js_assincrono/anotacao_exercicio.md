
# Exercício

- Consumir a API do CEP para obter informações de um endereço específico
  - Mostrar os dados do endereço no console

- Consumir a API de Livros para atualizar um livro e testar os casos:
  - Caso de sucesso: atualização de um livro existente.
  - Caso de erro: atualização de um livro inexistente.
  - Caso de erro: atualização de um livro sem passar os dados no body.
