IF ELSE OU SWITCH CASE? QUAL USAR?

IF ELSE

If Else é muito versátil para quando precisamos verificar qualquer tipo de condição, desde comparações númericas até expressões booleanas complexas.

Devemos usar quando temos várias condições que envolve operadores lógicos ou quando as comparações não são baseadas em um único valor ou tipo de dado.

SWITCH CASE

Switch Case é muito utilizado quando precisamos comparar um único valor à vários valores possíveis como uma variável númerica ou string

Devemos utilizar quando estamos comparando uma única variável com valores específicos ou quando a quantidade de possiveís condições e grande e torna o código IF ELSE extenso é muito difícil de ler.
