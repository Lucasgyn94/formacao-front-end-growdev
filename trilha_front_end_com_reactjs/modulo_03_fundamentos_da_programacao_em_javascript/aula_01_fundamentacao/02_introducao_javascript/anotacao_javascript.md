# JavaScript
* Desenvolvido em __1995__ por Brendan Eich, programador da Netscape

* Nasceu com o propósito de ser uma __linguagem de script__ para deixar a __navegação mais dinâmica__.

* Inicialmente chamado de __LiveScript__, e teve seu nome alterado para __JavaScript__ após uma parceria com a empresa responsável pela criação da linguagem __Java__.

* Em 1997, em associação ao __ECMA__, foi criada uma padronização do JavaScript chamada __ECMAScript__ para garantir o crescimento da linguagem seguindo algumas normas.

* JavaScript é uma linguagem de programação interpretada de alto nível.

* Junto do HTML e do CSS, formam a __base de toda a Web__
