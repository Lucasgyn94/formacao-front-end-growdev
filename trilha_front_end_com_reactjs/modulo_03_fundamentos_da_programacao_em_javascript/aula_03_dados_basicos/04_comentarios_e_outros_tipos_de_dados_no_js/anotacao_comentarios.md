## OUTROS TIPOS DE DADOS
### Nulo (null)
* Representa a ausência intencional de valor.
__tipo__: Object
__inicialização__: Deve ser explicitamente atribuída
__Uso Comun__: Indicar que uma variável intencionalmente não tem valor
__Verificação__: variable === null

### Indefinido (undefined)
* Representa a ausência de valor ou que a variável não foi inicializada.
__tipo__: undefined
__inicialização__: Acontece automaticamente quando a variável é declarada mas não inicializada
__Uso Comun__: Indicar que uma variável foi declarada mas ainda não foi inicializada, ou que uma função não retornou valor.
__Verificação__: typeof variable === 'undefined'
