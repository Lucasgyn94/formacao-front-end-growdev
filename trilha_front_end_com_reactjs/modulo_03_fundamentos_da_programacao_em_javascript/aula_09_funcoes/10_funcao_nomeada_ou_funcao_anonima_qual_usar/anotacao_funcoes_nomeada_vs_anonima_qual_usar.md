# Função Nomeada ou Função Anônima? Qual devo usar?
## Função Nomeada
* São úteis quando precisamos reutilizar a função em diferentes partes do código, além de ajudar na legibilidade e manutenção do código.

## Função Anônima
* Ideais para quanto precisamos de uma função para ser utilizada somente uma vez ou quando queremos passar essa função como parâmetro para outras funções.
