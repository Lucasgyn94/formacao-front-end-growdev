# WHILE
* Se não sabemos o número de iterações que o bloco de código terá, e se a condição precisa ser verificada antes de executar o trecho de código, usamos o __While__.

# DO WHILE
* Se não sabemos o número de iterações que o bloco de código terá, e se a condição pode ser verificada depois de executar o primeiro trecho de código, usamos o __Do While__.

# FOR
* Se sabemos o número de iterações que o bloco de código terá, e preferencial se usar o __for__.
