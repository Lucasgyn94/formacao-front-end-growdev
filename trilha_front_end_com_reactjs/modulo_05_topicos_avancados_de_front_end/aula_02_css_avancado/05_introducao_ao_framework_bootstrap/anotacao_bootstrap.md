# Framework

__Framework é um conjunto de conceitos, etapas, ações ou estratégias, que serão usados para resolver um problema específico.__

## Exemplos:

* Framework para construir uma casa.
* Framework para contratação.
* Framework para criar um sistema, etc.

## Na programação

Um __framework__ é um conjunto de bibliotecas ou componentes que são usados para criar uma base onde sua aplicação será construída.

Ou seja, são códigos prontos que podem ser utilizados no desenvolvimento de seu projeto.

## Onde pode ser aplicado?
* Administração
* Recursos humanos
* Construção
* Manutenção
* Engenharia
* Vendas
* Computação

## Bootstrap

__Twitter Bootstrap__ é um framework __Front-End__ utilizado para desenvolver aplicações web, desenvolvido pelo Twitter em 2010.

Em 2011 foi transformado em código aberto, e teve seu nome transformado para __Bootstrap__.

## Como funciona?

O __Bootstrap__ é formado por uma série de arquivos __CSS__ e __JavaScript__.

Esses arquivos são responsáveis por atribuir características específicas aos elementos da página, simplificando a criação de formulários, tabelas, apresentação de dados e muito mais!

__Com o Bootstrap, nosso trabalho vai ficar mais padronizado e simples!__

## Como utilizar?
* Download da versão compilada dos códigos CSS e JavaScript.
* Utilizar os links para acessar o Bootstrap via CDN.
* Baixar o framework por meio de gerenciadores de pacotes.
