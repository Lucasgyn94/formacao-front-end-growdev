# Exercício

## Capturar e Exibir Texto de Elementos

Crie uma página HTML com os seguintes elementos:
   1. Um título __<h1>__ com o texto "Bem-vindo à Página de Exercícios DOM".
   2. Um parágrafo __<p>__ com o texto "Este é o parágrafo 1".
   3. Outro parágrafo __<p>__ com o texto "Este é o parágrafo 2".
   4. Um botão com o texto "EXIBIR TEXTO".

Quando o usuário clicar no botão, crie uma função que capture e exiba em um alert o texto dosegundo parágrafo.

### Requisitos:
1. Utilize __getElementById__ ou __getElementsByTagName__ para capturar o segundo parágrafo.
